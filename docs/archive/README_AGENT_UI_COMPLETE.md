## 📊 מה רואים בכל סוכן?

### 1. **רמת ביטחון** (Confidence)
- 🟢 80%+ = גבוה
- 🟡 60-80% = בינוני
- 🔴 <60% = נמוך

### 2. **השפעה על המחיר** (Impact)
- 🟢 +5%+ = העלאה משמעותית
- 🔵 0-5% = השפעה קלה
- 🟠 0 to -5% = הורדה קלה
- 🔴 -5%- = הורדה משמעותית

### 3. **נימוקים מפורטים**
- למה הסוכן הגיע למסקנה הזו
- איזה נתונים הוא השתמש
- מה הייתה ההחלטה

### 4. **זמן ביצוע**
- כמה זמן לקח לסוכן לרוץ
- מועיל לאופטימיזציה
