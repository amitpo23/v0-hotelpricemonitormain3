המערכת החדשה מספקת **שקיפות מלאה** לתהליך קבלת ההחלטות של AI בתמחור מלונות. כל חיזוי מחיר מבוסס על 8+ סוכני AI עצמאיים, וכעת תוכל לראות בדיוק:

## 🧠 הסוכנים - מדריך מלא

### 1. **💰 Budget Agent**
- **תפקיד**: ניתוח תקציב חודשי ויעדי הכנסה
- **קלט**: תקציב יעד, הכנסה נוכחית, ימים שנותרו
- **פלט**: מכפיל מחיר (0.95-1.15)
- **רמת ביטחון**: 85%

### 2. **⚡ Velocity Agent**
- **תפקיד**: ניתוח מהירות הזמנות ב-7 ימים אחרונים
- **קלט**: מספר הזמנות, מגמה
- **פלט**: מכפיל מחיר (0.92-1.08)
- **רמת ביטחון**: 80%

### 3. **📅 Events Agent**
- **תפקיד**: זיהוי אירועים, פסטיבלים, כנסים
- **קלט**: תאריך, מיקום, רדיוס 7 ימים
- **פלט**: רשימת אירועים + מכפיל כולל
- **רמת ביטחון**: 70-85% (תלוי במקורות)
- **מקורות**: Tavily API, Timeout.com, Eventbrite

### 4. **📊 Historical Agent**
- **תפקיד**: השוואה לשנה הקודמת (Year-over-Year)
- **קלט**: מחירים היסטוריים מאותו תאריך
- **פלט**: מגמה + המלצה
- **רמת ביטחון**: 70%

### 5. **📈 Statistics Agent**
- **תפקיד**: נתונים סטטיסטיים ממשלתיים (CBS)
- **קלט**: תיירות, תעסוקה, מדדים כלכליים
- **פלט**: מחיר שוק ממוצע + סנטימנט
- **רמת ביטחון**: 65-75%

### 6. **👥 Competitor Agent**
- **תפקיד**: ניתוח מחירי מתחרים
- **קלט**: סריקות Apify/Bright Data
- **פלט**: מחיר ממוצע + מיקום יחסי
- **רמת ביטחון**: 65-85% (תלוי בכמות נתונים)

### 7. **🌊 Seasonality Agent**
- **תפקיד**: עונתיות (קיץ/חורף/חגים)
- **קלט**: חודש, שבוע בחודש
- **פלט**: מכפיל עונתי (0.85-1.25)
- **רמת ביטחון**: 90%

### 8. **🎯 Occupancy Agent**
- **תפקיד**: תפוסה נוכחית של המלון
- **קלט**: חדרים תפוסים / סה"כ חדרים
- **פלט**: מכפיל תפוסה (0.90-1.20)
- **רמת ביטחון**: 95%

## 🎨 צבעים ואינדיקטורים

### רמת השפעה (Impact)
- 🟢 **ירוק** (`+5%` ומעלה) - השפעה חיובית גבוהה
- 🔵 **כחול** (`0%` עד `+5%`) - השפעה חיובית קלה
- 🟠 **כתום** (`0%` עד `-5%`) - השפעה שלילית קלה
- 🔴 **אדום** (`-5%` ומטה) - השפעה שלילית גבוהה

### רמת ביטחון (Confidence)
- 🟢 **גבוה** (80%+) - נתונים מהימנים
- 🟡 **בינוני** (60-80%) - נתונים חלקיים
- 🔴 **נמוך** (<60%) - נתונים מוגבלים

### סטטוס סוכן
- ✅ **הושלם** - הסוכן רץ בהצלחה
- ⚠️ **נכשל** - הסוכן נתקל בשגיאה
- ⏳ **בביצוע** - הסוכן עדיין רץ

## 💡 טיפים למשתמשים

### 1. **הבנת החלטות מתמחור**
- שים לב לסוכנים עם השפעה גבוהה (>10%)
- סוכן Events יכול להעלות מחירים משמעותית באירועים גדולים
- Occupancy Agent חשוב במיוחד כשהמלון מתמלא

### 2. **טיפול בביטחון נמוך**
אם רואה סוכן עם ביטחון נמוך (<60%):
- בדוק אם יש נתונים חסרים (לדוגמה: סריקות מתחרים)
- הסוכן ישפיע פחות על המחיר הסופי
- שקול להוסיף מקורות נתונים

### 3. **זיהוי הזדמנויות**
- Events Agent מצא אירוע גדול = העלה מחיר
- Competitor Agent מראה שאתה זול = העלה מחיר
- Occupancy גבוה = העלה מחיר

### 4. **אופטימיזציה**
- השתמש ב-Agent Logs כדי להבין מגמות
- עקוב אחרי Events Agent - תכנן מראש לאירועים
- השווה Historical Agent - למד מהעבר
