# 📊 דשבורד תקציב מתקדם - מדריך מלא

## 🎯 מה זה עושה?

הדשבורד הפיננסי החדש עונה על השאלות החשובות ביותר:

### 1️⃣ **כמה הזמנות חסרות לי כדי להגיע לתקציב?**
- חישוב מדויק של מספר ההזמנות הנדרשות
- פירוט יומי: כמה הזמנות ליום
- בדיקה אם זה בכלל אפשרי עם התפוסה הנוכחית

### 2️⃣ **מה החיזוי להכנסות שלי אם אמשיך לפי המלצות?**
- חיזוי הכנסות לסוף החודש
- על בסיס הזמנות קיימות + קצב הזמנות נוכחי
- פירוט: בפועל + מאושר = צפוי סוף חודש

## 🔧 איך זה עובד מאחורי הקלעים?

### API Endpoint חדש
```
GET /api/budget/analysis?hotelId=XXX&year=2026&month=1
```

**מחשב:**
1. ✅ Target Revenue (מ-revenue_budgets)
2. ✅ Actual Revenue (מ-revenue_tracking)
3. ✅ Booked Revenue (מ-bookings future)
4. ✅ Budget Gap (פער)
5. ✅ Days Remaining (ימים שנותרו)
6. ✅ Bookings Needed (הזמנות נדרשות)
7. ✅ Performance Status (סטטוס ביצועים)
8. ✅ Recommendation (המלצה)

### חישוב הזמנות נדרשות
```typescript
const budgetGap = targetRevenue - totalExpectedRevenue
const bookingsNeeded = Math.ceil(budgetGap / avgRoomPrice)
const roomsNeededPerDay = Math.ceil(dailyRevenueNeeded / avgRoomPrice)
```

### חישוב חיזוי
```typescript
const totalExpectedRevenue = actualRevenue + bookedRevenue
const budgetGap = targetRevenue - totalExpectedRevenue
```

### בדיקת אפשרות
```typescript
const maxPossibleBookings = totalRooms * daysRemaining
const achievable = bookingsNeeded <= maxPossibleBookings * (currentOccupancy / 100)
```
